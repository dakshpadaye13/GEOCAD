# GEOCAD Startup Instructions

Whenever you restart your computer and want to get the GEOCAD Digital Twin running instantly, simply copy the prompt below and paste it into the agent chat:

---

**Copy this prompt:**

> Please start the GEOCAD Digital Twin platform. 
> 1. Run the backend server by executing `node mockServer.js` in the `c:\Users\daksh\GEOCAD\backend` directory.
> 2. Run the frontend development server by executing `npm run dev` in the `c:\Users\daksh\GEOCAD\frontend` directory.
> 3. Once both servers are up and running, provide me with the clickable localhost link to the frontend so I can view the fully functional platform!
